# Sistema de Capacitação Tecnológica e Gestão de Conhecimento

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de estruturar e organizar o compartilhamento de conhecimento técnico por meio de uma plataforma de capacitação tecnológica, promovendo o aprendizado contínuo, a inclusão digital e o acesso facilitado a conteúdos voltados à área de tecnologia.

A aplicação foi idealizada como um ambiente de apoio ao desenvolvimento de habilidades técnicas, permitindo a organização de trilhas de aprendizagem, materiais complementares e conteúdos educativos de forma intuitiva, acessível e escalável.

Além do contexto técnico, o projeto também foi utilizado como base para uma ação extensionista acadêmica, buscando aproximar conhecimentos adquiridos no curso de Sistemas de Informação da realidade social, incentivando o aprendizado de jovens e pessoas interessadas na área de tecnologia.

---

## 🎯 Objetivos do Projeto

* Organizar conteúdos técnicos em trilhas estruturadas de aprendizagem;
* Facilitar o acesso a materiais educacionais na área de tecnologia;
* Promover inclusão digital e autonomia no aprendizado;
* Disponibilizar um ambiente intuitivo para capacitação técnica;
* Aplicar conceitos acadêmicos em um cenário prático;
* Auxiliar processos de aprendizagem tecnológica e formação profissional.

---

## 🚀 Funcionalidades

* Cadastro e gerenciamento de usuários;
* Organização de trilhas de aprendizagem;
* Controle de conteúdos educacionais;
* Materiais complementares em PDF;
* Organização modular de conteúdos;
* Interface intuitiva e amigável;
* Scripts de automação para configuração do ambiente (.bat);
* Estrutura de banco de dados relacional;
* Foco em usabilidade e acessibilidade.
